# 已知限制

`domains` / `certs` / `deploy` 的行为都在 2026-10 用各云真实账号验证过，用 TLS 握手核对过边缘实际下发的证书；腾讯云 EdgeOne 例外，账号没开通，只经过模拟测试。`issue` 只有阿里云云解析经过真实签发验证；其余 DNS 服务商按官方文档实现，只经过模拟测试（其中 DNSPod、火山引擎、华为云、百度智能云用真实账号确认过签名与接入点）。每个厂商一节，「查询」对应 `domains` / `certs`，「部署」对应 `deploy`，「签发」对应 `issue`。

## 通用

- **证书没有 CN**：Let's Encrypt 的 shortlived / tlsserver 配置文件签发的证书只有 SAN、没有 CN。阿里云 OSS，腾讯云 CDN、COS、点播，火山引擎 CDN、点播、直播、veImageX，百度智能云 CDN，七牛云 CDN 不接受这类证书（或者收下了但不生效），这些域名会记为 `CertWithoutCommonName` 失败，不上传也不修改，`--dry-run` 时就会报出来。华为云云证书管理同样拒收，直播、OBS 改为直接传证书内容（这样的证书在 `certs` 里看不到）。要部署到这些服务，请用带 CN 的证书，比如 Let's Encrypt classic 配置文件签发的。
- **生效时间**：云接口受理就算成功。实测边缘生效从十几秒到几分钟不等：华为 OBS、直播在 1 分钟内，CDN 类 1–7 分钟。关闭 HTTPS 后，个别边缘节点可能还会继续下发原证书一段时间。
- `domains` 表格里的到期时间按本机时区显示，JSON 统一是 UTC。
- **两天内重签的证书**：`deploy` 判断「已是这张证书」时，比的是到期时间和签发时间（容差 48 小时，有的服务只精确到天）。当前证书的 SAN 有新证书没有的域名时，会按不同证书处理；但多数服务不返回 SAN（如阿里云 CDN、OSS），这时两天内重签的证书仍会被当成已部署，需要 `-d` 点名并加 `--force`。

签发（`issue`）：

- 只支持 Let's Encrypt 的 DNS-01 验证，证书用 classic 配置文件（带 CN，2027-02 起有效期 64 天，2028-02 起 45 天）。不支持 IP 证书、HTTP-01 验证，以及 `_acme-challenge` 已 CNAME 到其他域名的 DNS 别名模式。
- 验证记录只加在默认线路上。是否生效以直接查询 zone 的权威 NS 为准；所有权威 NS 都连不上时，固定等 30 秒后继续。
- 进程被 SIGINT / SIGTERM 中止时会先删除本次加的记录再退出（最多等 30 秒）；被 SIGKILL 强杀时来不及删除。
- Let's Encrypt 会复用近期已通过的验证（目前 30 天内，2027-02 起缩短为 10 天），这时不加 TXT 记录，`dns[]` 里也不列这些域名。
- 复用判断只看保存目录里的那一张证书。主域名（层级最少的域名）决定保存目录，所以同一组域名不论 `-d` 怎么排序都落在同一个目录。

## 阿里云

查询：

- 视频点播只查上海地域（`vod.cn-shanghai.aliyuncs.com`）；点播证书只有 SAN，没有 CN。
- 直播推流域名不能配 HTTPS，显示为关闭。直播关闭 HTTPS 时证书会一并删除，不存在「绑了证书但关着 HTTPS」的状态。
- ESA 只查中国站接入点（`esa.cn-hangzhou.aliyuncs.com`），国际站（`ap-southeast-1`）还没适配。
  - 证书配置在站点上，记录绑的是哪张证书，是按证书的 CN 和 SAN 匹配出来的。多张都匹配时按 ESA 的优先级取：在有效期内、配置时间较晚的优先；RSA、ECC 同时有效时取先到期的那张。
  - HTTPS 开启的条件：站点的 SSL/TLS 配置（全局配置加 SSL/TLS 规则）对该域名开了 HTTPS，并且有已签发的匹配证书。只有申请中或申请失败的证书时记为关闭。
  - `extra.httpsSwitch` 是开关状态，取值 `on` / `off` / `partial`；`extra.httpsRule` 是决定结果的那条规则名。`partial` 表示有规则的条件没法按域名判断（比如引用了自定义列表，或者用了无法解析的写法），这时按开启处理并照常展示证书，宁可多报到期。SSL/TLS 配置查询失败时没有 `httpsSwitch`，HTTPS 只按证书判断。
  - 泛域名记录按记录名本身（如 `*.example.com`）匹配规则；SaaS 域名看它自己的 SSL 开关。
  - 只解析不加速的记录不列出；边缘函数、边缘容器和四层加速的记录暂不支持。
  - 在 ESA 上传的证书也会出现在 `certs`（数字证书管理服务）里，名称是 ESA 的证书 ID。
- 数字证书管理服务的有效期取接口返回的毫秒时间戳。个别证书缺这个字段时，退回到只有日期的 EndDate，按到期当天 23:59:59（北京时间）算。

部署：

- 证书上传到数字证书管理服务（中国站，cn-hangzhou）。私钥会先转成 PKCS#1（RSA）或 SEC1（ECC）格式再上传，这是阿里云的要求。按证书指纹查重，同一张证书不会重复上传。
- 直播：推流域名不能配 HTTPS。直播的 HTTPS 证书列表查询失败时，没法判断直播域名是否开着 HTTPS，记为 `HttpsStateUnknown`。
- ESA：
  - 普通记录的证书挂在站点上。站点上同算法、而且域名都被新证书覆盖的旧证书会被原地替换，不占站点证书配额（免费版只有 2 张）；否则往站点上追加新证书，旧证书不删。
  - 加入一种算法的证书不会替换另一种算法的证书。比如域名上原来是 ECC 证书，部署 RSA 证书后，ECC 证书到期前仍可能下发给支持 ECC 的客户端，结果里会有提示。
  - 站点下被新证书覆盖的记录要全部满足更新条件才会上传，否则整站跳过（`shared_cert_blocked`）。
  - 没开 HTTPS 的普通记录不能用 CLI 部署：要改站点的 SSL/TLS 规则，影响面超出单个域名。
  - SSL/TLS 配置查询失败时，该站点下有证书的记录记为 `HttpsStateUnknown`。
- OSS 泛域名 CNAME 没有专门适配。

签发（云解析 DNS，已用真实账号签发验证）：

- TTL：免费版、个人版 600 秒，其他版本 60 秒，被拒时退回 600 秒。
- 域名列表没有「未接入」状态：NS 不在阿里云的域名也会被选中，等待生效超时时报 NS 不一致。

## 腾讯云

查询：

- 平台默认域名按后缀识别（接口里没有区分字段）：`myqcloud.com`、`vod-qcloud.com`、`tlivecloud.com`、`tencentcos.cn`，标记为 `extra.managed: "platform"`。点播、直播的平台域名始终由平台提供 HTTPS，CDN 的平台域名以 HTTPS 开关为准。
- CDN 的证书名取 SSL 证书的备注名。直播推流域名不能绑证书，显示为关闭。
- COS 只列存储桶的自定义源站域名。COS 没有单独的 HTTPS 开关，以该域名的证书配置为「已启用」为准；自定义域名本身被停用但仍绑着证书时照常显示开启，因为边缘仍会下发该证书。经过 CDN 加速的 COS 域名出现在腾讯云 CDN 的结果里。每个域名要单独查一次证书配置（并发 5），域名多时请求较多。

部署：

- EdgeOne 只经过模拟测试。挂了多张证书但查不到算法的 EdgeOne 域名不处理；原来用免费证书的 EdgeOne 域名，更新后改为托管证书。
- CDN 部署不会替你打开 HTTPS 计费开关（HttpsBilling）。开关关着时证书照常部署，结果里会提示 HTTPS 请求会被拦截。
- 不支持：直播推流域名、点播里由 EdgeOne 分发的域名、锁定中的点播域名。COS 已停用的自定义域名只换证书，不会启用域名（边缘照常下发新证书）。
- 上传结果里的 `reused` 依赖 SSL 证书列表的读权限，没有这个权限时一律报 `false`，但不会重复创建证书。

签发（DNSPod，只经过模拟测试）：

- 只走中国站接口 `dnspod.tencentcloudapi.com`。暂停解析、被封禁的域名不参与查找（报 `ZoneNotFound`）；DNS 没指向 DNSPod 的域名照样参与，多家都托管时按 DNSPod 分配的 NS 判定。
- TTL 免费套餐 600 秒，付费套餐 60 秒，被拒时退回 600 秒。新增记录有索引延迟，遇到「记录已存在」时最多再等 30 秒查记录 ID。

## 火山引擎

查询：

- 视频点播、veImageX 只查华北和亚太东南（柔佛）两个地域。它们的 HTTPS 配置要逐个域名查询，域名多时较慢。
- 视频直播的读接口没有 HTTPS 开关。绑了证书并开启 HTTPS 时域名才带证书链 ID，CLI 以此判断开没开；绑了证书但关着 HTTPS 的域名显示为关闭，虽然边缘实际仍会用该证书完成 TLS 握手。推流域名的证书用于 RTMPS / HTTPS 推流，同样会列出。
- TOS 没有 HTTPS 开关，绑了证书就能 HTTPS 访问。证书状态为 `CertNotExist`（证书已删除）或 `RoleNotExist`（TOS 无法访问证书中心）时，实际下发的是 TOS 默认证书，因此记为关闭，原证书 ID 和状态放在 `extra.certId` / `extra.certStatus`。
- DCDN 绑了证书但关着 HTTPS 的域名按开关记为关闭（实测边缘仍下发该证书）。
- CDN、点播的双证书（RSA + ECC）是平台白名单功能。
- `certs` 只列证书中心里已签发的 SSL 证书，不包括视频直播证书管理里上传的证书、CDN 自托管证书和私有 CA 证书。

部署：

- 视频直播：
  - 拉流域名不能自动更新证书。换证书用的 `BindCert` 会按请求参数重设 TLS 版本等配置，而直播的读接口读不出当前的 TLS 版本，只能去控制台更换。推流域名不受影响。
  - 点名给拉流域名部署时，最低 TLS 版本设为 1.2。
  - 直播证书上传到直播自己的证书管理，`certs` 里看不到。
- veImageX 会读出全部 HTTPS 配置，只换证书后整块写回。从没开过 HTTPS 的域名部署时，TLS 版本取 1.1–1.3，不开 OCSP。
- DCDN 部署后会读回确认 HTTPS 已开启；绑了证书但关着 HTTPS 的域名会单独打开开关。
- TOS 证书状态为 `RoleNotExist` 时不处理，需要先在 TOS 控制台完成访问证书中心的授权。
- CDN、点播的双证书只替换同算法的那张；双证书域名查不到算法时不处理。
- 证书中心与直播不接受自建 CA 签发、链不完整的证书。

签发（云解析 DNS，只经过模拟测试）：

- 只查状态为「正常」或「请变更 DNS 服务器」的域名；「待找回」「未使用 TrafficRoute 解析」等状态的域名不参与查找，刚把 NS 改到火山引擎、控制台还没显示「正常」时会报 `ZoneNotFound`。
- TTL 按版本取最小值：免费版 600 秒、专业版 300 秒、企业版 60 秒、旗舰版 / 尊享版 1 秒。免费版子域名最多 5 级，层级太深的验证记录会添加失败。

## 华为云

查询：

- 只适配中国站：CDN 走 `cdn.myhuaweicloud.com`，证书列表走 `scm.cn-north-4.myhuaweicloud.com`。
- CDN 一次拉取所有企业项目下的域名。CDN 双证书只支持「国际 + 国密」；关闭 HTTPS 时证书会一并删除。
- 视频直播按 IAM 项目逐个地域查询，范围是 cn-north-4、cn-north-1、cn-east-3、ap-southeast-3、ap-southeast-2，只查每个地域的主项目，没用直播的地域静默跳过。
  - 直播没有 HTTPS 开关，播放域名配了证书就算开启 HTTPS；没配证书时下发的是平台默认证书。
  - 有效期取自域名当前证书的 PEM。证书列表接口的时间比真实值早 8 小时，只在取不到 PEM 时修正后使用。
- OBS 只列对象桶，不包括并行文件系统。自定义域名绑了服务端证书（含国密）才算 HTTPS。
- 证书列表的到期时间不带时区，实测是北京时间。

部署：

- CDN 直接传证书内容，不经过云证书管理（用云证书管理里的证书绑定 CDN，需要先在控制台授权），所以 CDN 部署的证书在 `certs` 里看不到。直播、OBS 会先上传到云证书管理再绑定。
- CDN、直播的国密证书只有由云证书管理托管时才能保留。自己上传的国密证书读不到私钥，这类域名会跳过，需要去控制台更换。
- 直播推流域名不能配证书。
- OBS 只设置国际证书，国密证书和客户端 CA 证书不动；OBS 列表不返回国际证书的算法。

签发（云解析服务 DNS，只经过模拟测试）：

- 公网域名是全局资源，统一走华北-北京四（cn-north-4）接入点。只查状态为正常、更新中的公网域名；不在默认企业项目里的域名可能列不出来。
- 同名下已有 TXT 记录集时把验证值追加进去，清理时只去掉验证值，原记录集的 TTL 不变；新建的记录集 TTL 为 1 秒。同名 TXT 记录集已暂停时报 `RecordSetNotActive`，处理中超过 30 秒时报 `RecordSetNotSteady`。

## 百度智能云

查询：

- 只覆盖境内 CDN，海外 CDN 不支持。每个 CDN 域名只能绑一张证书。
- HTTPS 以「已开启 HTTPS 的域名列表」为准。绑了证书但关着 HTTPS 的域名记为关闭：实测边缘握手时仍下发该证书，但 HTTPS 请求返回 403 httpsDisabled。这个接口失败时，退回到逐个域名查 HTTPS 配置（并发 5），域名多时较慢。
- 证书的 CN 和 SAN 按证书 ID 从证书管理补全（该列表里的 certCommonName 字段其实是证书名）。
- 没开通 CDN 的账号，只读接口照常返回空列表，所以会显示 0 个域名，不提示未开通。
- `certs` 只列证书管理里的证书，不单独查 SSL 证书服务里购买的证书。用平台通用证书（`cert-common`）的域名没有到期时间。

部署：

- 只替换国际证书（RSA / ECC 二选一），国密 HTTPS 证书不处理。
- 证书管理按证书详情里的 SHA-1 指纹查重，同名同到期的 RSA、ECC 两张证书不会互相复用。

签发（智能云解析，只经过模拟测试）：

- 只查状态为 running 的域名（百度只解析已备案的域名，NS 修改后系统更新要 24 小时，这期间报 `ZoneNotFound`）。
- TTL 按版本取最小值：基础版 300 秒、普惠版 120 秒、企业版 1 秒；基础版子域名最多 5 级。

## 七牛云

查询：

- 只支持 CDN（含全站加速）域名，不包括对象存储 Kodo 的自定义域名。七牛给新建 bucket 自动分配的测试域名（`*.clouddn.com`）不列出。
- 泛域名按七牛的写法以点开头，比如 `.example.com`。
- 已下线、冻结的域名也会列出，用 `status` 区分。
- 一个域名只能绑一张证书，降级为 HTTP 时证书会被解绑。
- 开了 HTTPS 的域名要逐个查详情。七牛接口限 10 QPS，域名多时约每秒处理 8 个。

部署：

- 泛子域名的 HTTPS 继承自泛域名，不能单独部署，请对泛域名部署。
- 上一次配置还在处理中的域名，七牛会拒绝修改，需要稍后重新执行。
- 部署（开启 HTTPS）时默认打开 HTTP/2，不强制跳转；更新时强制跳转、HTTP/2、TLS 版本保持原样。
- 七牛拒收有效期太短的证书：实测 6 天的 Let's Encrypt 短期证书被拒，错误码 400322。

## 其他 DNS 服务商（签发）

七牛云没有 DNS 服务。以下 6 家只用于 `issue`，都只经过模拟测试。

Cloudflare：

- 只用已激活、完整接入（full）的 zone；CNAME 接入（partial）、Secondary DNS、待接入的 zone 不参与查找。
- 只支持 API Token。令牌缺 Zone Read 时列不出 zone，表现为 `ZoneNotFound`。TTL 60 秒。

AWS Route 53：

- 只支持全球区（`route53.amazonaws.com`），不支持 AWS 中国区。凭证只读环境变量，不读 `~/.aws/credentials`，不支持 `AWS_PROFILE`、SSO、实例角色（可以先用 `aws configure export-credentials --format env` 导出临时凭证）。
- 私有 zone 不列出。同名 TXT 记录集是别名记录、用了加权 / 地理等路由策略时不做改动，报 `UnsupportedRecordSet`。追加到已有记录集时沿用原 TTL，新建为 60 秒。

Google Cloud DNS：

- 只支持服务账号 JSON 密钥文件，不支持 `gcloud auth application-default login` 的用户凭证、工作负载身份联合、元数据服务器上的默认服务账号。只查一个项目（`GOOGLE_CLOUD_PROJECT`，没设置时用密钥里的 `project_id`），私有 zone 不列出。
- 配了路由策略的 TXT 记录集不做改动，报 `UnsupportedRecordSet`。

Azure DNS：

- 只支持全球版 Azure，不支持 Azure 中国（世纪互联）和政府云。只支持服务主体 + 客户端密码，不支持托管身份、`az login`。只查 `AZURE_SUBSCRIPTION_ID` 这一个订阅，私有 DNS 区域不列出。

DigitalOcean：

- 接口不返回域名的 NS，也没有「已接入」状态：NS 没指向 DigitalOcean 的域名也会被选中，等待生效超时时报 NS 不一致。TTL 30 秒。

GoDaddy：

- 用 Classic Developer Key（sso-key）。GoDaddy 文档说这种鉴权计划在 2026 年停用，改用 Personal Access Token；停用后需要升级 sslbear-cli。账号不满足 API 开放条件时所有请求返回 403。
- 只列出在 GoDaddy 注册、状态为 ACTIVE、NS 为 `*.domaincontrol.com` 的域名；注册在别家、只在 GoDaddy 托管 DNS 的域名，以及用了自定义 NS 的域名列不出来。
- 记录没有 ID：删除时读出同名的全部 TXT，去掉验证值后整组写回。TTL 600 秒。
