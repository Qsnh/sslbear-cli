# 已知限制

每节分三类：**不支持**、**需要你处理**、**注意**（结果可能和你预期不一样的地方）。先看[通用](#通用)，再看你用到的那家。

查询（`domains` / `certs`）、部署（`deploy`）、签发（`issue`）都在 2026-10 用真实账号验证过。例外：腾讯云 EdgeOne、GoDaddy 只做过模拟测试；百度智能云解析实测签不出证书。

## 通用

需要你处理：

- **部署的证书要带 CN。** 很多服务不收没有 CN 的证书，结果里报 `CertWithoutCommonName`，不做任何改动（`--dry-run` 就能看到）。`issue` 签的证书带 CN；Let's Encrypt shortlived / tlsserver 配置签的没有 CN，不要用。
- **部署完等几分钟再检查。** 云接口受理就算成功，边缘生效要十几秒到几分钟（CDN 类 1–7 分钟）。
- **48 小时内重签的证书可能被跳过。** `deploy` 靠到期时间和签发时间判断「已经是这张证书」，多数服务不返回证书里的域名，两天内重签的会被当成已部署。确实要换时，用 `-d` 点名并加 `--force`。
- **`issue` 运行中别强杀。** Ctrl+C 会先删掉验证用的 TXT 记录再退出（最多等 30 秒）；`kill -9` 来不及删，要去 DNS 里手动删 `_acme-challenge` 记录。

不支持：

- `issue` 只支持 Let's Encrypt 的 DNS 验证。不支持 IP 证书、HTTP 验证，也不支持把 `_acme-challenge` CNAME 到其他域名的委托方式。

注意：

- Let's Encrypt 证书有效期在缩短：现在 90 天，2027-02 起 64 天，2028-02 起 45 天。
- 同一组域名、同算法的证书还剩 30 天以上时，`issue` 直接复用，不重新签发。只看保存目录里的那一张；同一组域名不论 `-d` 怎么排序，都存在同一个目录。
- Let's Encrypt 近期验证过的域名（现在 30 天内，2027-02 起 10 天）不会再加 TXT 记录。
- 本机开着 Clash / Surge 等代理的 fake-ip 模式时，查不到权威 DNS，`issue` 会固定多等 90 秒。
- DNS 服务商个别节点同步慢、导致验证失败时，`issue` 会自动重试一次。每次失败都占 Let's Encrypt 的失败配额（每个域名每小时 5 次）。
- 关闭 HTTPS 后，个别边缘节点可能还会下发原证书一段时间。
- `domains` 表格里的时间按本机时区显示，`--json` 输出是 UTC。

## 阿里云

不支持：

- ESA 国际站（只查中国站）；ESA 的边缘函数、边缘容器、四层加速记录。只解析不加速的 ESA 记录不列出。
- 视频点播只查上海地域。
- 直播推流域名不能配 HTTPS（阿里云本身的限制）。
- OSS 泛域名 CNAME 没有适配。

需要你处理：

- **ESA 没开 HTTPS 的记录，CLI 不会部署。** 开 HTTPS 要改站点的 SSL/TLS 规则，影响整个站点，请先在控制台开好。
- **用阿里云解析签发时，域名的 NS 要指向阿里云。** NS 不在阿里云的域名也会被选中，要等到超时才报 NS 不一致。

注意：

- **ESA 部署会原地替换旧证书**：站点上同算法、域名都被新证书覆盖的旧证书直接被替换（免费版站点只能放 2 张证书）；不满足时追加新证书，旧证书不删。
- ESA 部署 RSA 证书不会替换 ECC 证书，反过来也一样。旧的那张到期前，仍可能下发给支持该算法的客户端。
- ESA 站点里被新证书覆盖的记录，有一条不满足替换条件，整个站点都跳过（`shared_cert_blocked`）。
- ESA 的 HTTPS 状态按站点的 SSL/TLS 配置判断。规则没法按域名判断时（比如引用了自定义列表），显示为 `partial`，按开启处理。

## 腾讯云

不支持：

- 直播推流域名（不能绑证书）。
- 部署：点播里由 EdgeOne 分发的域名、锁定中的点播域名。
- DNSPod 国际站；暂停解析、被封禁的域名（报 `ZoneNotFound`）。

需要你处理：

- **CDN 的 HTTPS 计费开关（HttpsBilling）要你自己打开。** CLI 不会替你开；开关关着时证书照常部署，但 HTTPS 请求会被拦截（结果里有提示）。

注意：

- EdgeOne 只做过模拟测试，正式使用前先 `--dry-run` 核对。原来用免费证书的 EdgeOne 域名，部署后改为托管证书；挂了多张证书、查不到算法的不处理。
- COS 只列存储桶的自定义源站域名；走 CDN 加速的 COS 域名算在 CDN 里。已停用的 COS 自定义域名只换证书，不会启用。
- 平台默认域名（`myqcloud.com`、`vod-qcloud.com`、`tlivecloud.com`、`tencentcos.cn` 结尾）也会列出，标为平台托管。

## 火山引擎

不支持：

- 视频点播、veImageX 只查华北和亚太东南（柔佛）两个地域。

需要你处理：

- **直播拉流域名要去控制台换证书。** 换证书的接口会重设 TLS 版本，而 CLI 读不出原来的值，所以默认不处理。用 `-d` 点名部署时，最低 TLS 版本会被设为 1.2。推流域名不受影响。
- TOS 证书状态为 `RoleNotExist` 时，先在 TOS 控制台授权它访问证书中心。
- 刚把 NS 改到火山引擎、控制台还没显示「正常」时，签发报 `ZoneNotFound`，等状态变正常再签。

注意：

- 证书中心和直播不收自建 CA 签发、链不完整的证书。
- 直播、DCDN 绑了证书但关着 HTTPS 的域名显示为关闭，实际边缘仍用该证书握手。DCDN 部署时会顺带打开 HTTPS。
- TOS 没有 HTTPS 开关，绑了证书就能 HTTPS 访问。证书被删或 TOS 无权访问证书中心时，实际下发的是 TOS 默认证书，显示为关闭。
- CDN、点播的双证书（RSA + ECC，白名单功能）只替换同算法的那张；查不到算法的双证书域名不处理。
- veImageX 首次开 HTTPS 时用 TLS 1.1–1.3、不开 OCSP。
- `certs` 只列证书中心的 SSL 证书。直播证书传到直播自己的证书管理，`certs` 里看不到。
- 云解析免费版子域名最多 5 级，层级太深的验证记录会添加失败。

## 华为云

不支持：

- 只适配中国站。
- 直播只查 cn-north-4、cn-north-1、cn-east-3、ap-southeast-3、ap-southeast-2 这几个地域的主项目。
- 直播推流域名不能配证书；OBS 并行文件系统不列出。

需要你处理：

- **自己上传的国密证书要去控制台换。** CDN、直播上这类证书读不到私钥，域名会被跳过。云证书管理托管的国密证书会保留。
- 云解析里同名 TXT 记录集被暂停时报 `RecordSetNotActive`，先在控制台启用或删除它。

注意：

- 直播没有 HTTPS 开关：播放域名配了证书就算开启，没配时下发的是平台默认证书。
- CDN 部署直接传证书内容，不经过云证书管理，`certs` 里看不到。没有 CN 的证书云证书管理不收，直播、OBS 也会改为直接传，同样看不到。
- OBS 只设置国际证书，国密证书和客户端 CA 证书不动。
- 云解析只查状态为正常、更新中的公网域名；不在默认企业项目里的域名可能列不出来。

## 百度智能云

不支持：

- 海外 CDN（只覆盖境内）。
- 部署只替换国际证书，国密 HTTPS 证书不动。

需要你处理：

- **用百度智能云解析的域名，请换别家 DNS 签发。** 2026-10 实测：记录增删正常，但 Let's Encrypt 境外验证点连不上百度的 NS（只有国内 IP），多次都是 `AcmeChallengeFailed`。

注意：

- 绑了证书但关着 HTTPS 的域名显示为关闭（边缘仍下发证书，但 HTTPS 请求返回 403）。
- 没开通 CDN 的账号显示 0 个域名，不会提示未开通。
- `certs` 只列证书管理里的证书，不含 SSL 证书服务里买的证书；用平台通用证书的域名没有到期时间。
- 智能云解析：不支持 .beer 等部分后缀；改 NS 后 24~48 小时内报 `ZoneNotFound`；基础版子域名最多 5 级。

## 七牛云

不支持：

- 对象存储 Kodo 的自定义域名（只支持 CDN / 全站加速）；七牛分配的测试域名 `*.clouddn.com` 不列出。
- 七牛没有 DNS 服务，不能用于 `issue`。

需要你处理：

- **泛子域名不能单独部署**（HTTPS 继承自泛域名），请对泛域名部署。
- 上一次配置还在处理中的域名会被七牛拒绝，稍后重跑。

注意：

- 七牛拒收有效期太短的证书：实测 6 天的 Let's Encrypt 短期证书报 400322。
- 泛域名按七牛的写法以点开头，如 `.example.com`。已下线、冻结的域名也会列出，看 `status`。
- 首次开 HTTPS 时打开 HTTP/2、不强制跳转；更新证书时保持原配置。
- 接口限 10 QPS，域名多时约每秒处理 8 个。

## 其他 DNS 服务商

这几家只用于 `issue`。

| 服务商 | 不支持 | 注意 |
| --- | --- | --- |
| Cloudflare | CNAME 接入（Partial）、Secondary DNS、未激活的 zone | 只支持 API Token。令牌缺 Zone Read 时报 `ZoneNotFound` |
| AWS Route 53 | AWS 中国区；私有 zone；`~/.aws/credentials`、`AWS_PROFILE`、SSO、实例角色（只读环境变量） | 用 `aws configure export-credentials --format env` 导出临时凭证。同名 TXT 是别名记录或用了加权 / 地理等路由策略时报 `UnsupportedRecordSet` |
| Google Cloud DNS | `gcloud auth application-default login` 的用户凭证、工作负载身份联合、元数据服务器的默认服务账号；私有 zone | 只用服务账号 JSON 密钥。只查一个项目（`GOOGLE_CLOUD_PROJECT`，没设时用密钥里的 `project_id`）。配了路由策略的 TXT 报 `UnsupportedRecordSet` |
| Azure DNS | Azure 中国（世纪互联）、政府云；托管身份、`az login`；私有 DNS 区域 | 只用服务主体 + 客户端密码，只查 `AZURE_SUBSCRIPTION_ID` 这一个订阅 |
| DigitalOcean | — | 不检查 NS：NS 没指向 DigitalOcean 的域名也会被选中，要等到超时才报 NS 不一致 |
| GoDaddy | 在别家注册、只在 GoDaddy 托管 DNS 的域名；用了自定义 NS 的域名 | 只做过模拟测试。GoDaddy 计划 2026 年停用现在用的 Developer Key 鉴权，停用后要升级 sslbear-cli。账号不满足 API 开放条件时所有请求返回 403 |
